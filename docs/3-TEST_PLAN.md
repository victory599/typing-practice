# 测试计划

## 1. 测试范围

本地打字练习应用：本机文件服务 API、前端构建，以及核心业务路径（词库、成绩、路径迁移、练习评分与近期体验改动）。

## 2. 环境

- Node.js
- 项目目录：`typing-practice`
- 启动：`npm run dev`（或 `npm run dev:server` + 前端）
- 前端构建：`npm run build`

## 3. 测试用例

| 编号 | 模块 | 步骤 | 预期 | 优先级 |
|------|------|------|------|--------|
| T01 | 服务健康 | 启动服务后请求 `GET /api/health` | 返回 `{ ok: true }` | 高 |
| T02 | 配置读取 | `GET /api/settings` | 含固定 `configPath`、`configPathFixed: true`、默认 `resolvedDataPath` | 高 |
| T03 | 种子范文 | **删除** `texts.json` 后首次读取 | 自动写入范文；若文件存在且为空数组则保持为空 | 高 |
| T04 | 新增文本 | `POST /api/texts` 合法标题正文 | 201，列表中可见 | 高 |
| T05 | 成绩写入 | `POST /api/results` 后 `GET /api/results` | 列表含刚写入记录 | 高 |
| T06 | 清空成绩 | `DELETE /api/results` | 列表为空 | 高 |
| T07 | 数据迁移 | 将 dataPath 迁到新目录再恢复默认 | 文件被移动；配置更新 | 高 |
| T08 | 配置不可改路径 | `PUT /api/settings` 尝试改 dataPath | dataPath 不被该接口修改 | 中 |
| T09 | 前端构建 | 执行 `npm run build` | 成功无报错 | 高 |
| T10 | 评分公式 | 对已知 correctChars / elapsedMs 手算对比 | 与 PRD 约定一致 | 中 |
| T11 | 练习页加载 | 打开练习页 | 可选文本与模式，可聚焦打字区 | 高 |
| T12 | 错误标红与退格 | 故意打错再退格 | 错误着色；退格后可改正确 | 高 |
| T13 | 随机选题 | 点击「随机」 | 切换到另一篇（尽量不同于当前） | 高 |
| T14 | 结算换一篇 | 结束后点「换一篇」 | 随机换文并重新可练；不跳词库 | 高 |
| T15 | 去词库 | 结算点「去词库」 | 进入词库页 | 中 |
| T16 | 恢复默认置灰 | 当前已是默认且输入未改 | 「确认」「恢复默认」不可点 | 高 |
| T17 | 批量删除 | 勾选后「删除所选」 | 选中项删除；`POST /api/texts/bulk-delete` | 高 |
| T18 | 全部删除 | 「全部删除」确认后 | 词库为空且刷新后不自动灌回范文 | 高 |
| T19 | 空格显示 | 含空格文本练习 | 空格为空白，不用 `·` | 中 |
| T20 | 下拉溢出 | 超长标题文本 | 练习文本下拉不撑破布局 | 中 |

## 4. 执行说明

- API 用例可用 curl 或同类工具
- 界面用例如 T11–T20 建议手工点验
- 结果记入 `docs/4-TEST_REPORT.md`
