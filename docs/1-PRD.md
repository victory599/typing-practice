# 产品需求说明（PRD）

## 1. 产品是什么

本地打字练习应用：在浏览器中练习打字，数据保存在本机文件夹，无需账号与云端。

## 2. 目标用户

希望在本机练习英文/字符级打字，并自行管理练习文本与成绩的人。

## 3. 核心功能

| 功能 | 说明 |
|------|------|
| 打字练习 | 展示待打文本；当前字符高亮；正确/错误着色；支持退格；打错可继续前进 |
| 实时指标 | WPM、准确率、用时/剩余时间、进度 |
| 练习模式 | 自由练完；限时 1 / 3 / 5 分钟 |
| 结算 | 展示 WPM、准确率、用时、错误数；可再练或换文本 |
| 词库管理 | 新增 / 编辑 / 删除练习文本；内置范文 |
| 成绩统计 | 历史列表；可手动清空成绩 |
| 设置 | 查看配置；修改**数据目录**路径并迁移（移动）；配置目录固定不可改 |
| 主题 | 浅色主题 |

## 4. 评分规则

- **WPM** = `(正确字符数 / 5) / 分钟`
- **准确率** = `正确字符数 / 已尝试字符数`（已打过的位置中正确占比）

## 5. 数据与存储

- **配置目录 `config/`**：固定在应用根目录，用户不可改路径；存放 `settings.json`（含数据路径、默认模式等）
- **数据目录 `data/`**：默认在应用根下；用户可改为其他本机路径；改路径时**移动**文件，不复制留双份
- 词库：`texts.json`；成绩：`results.json`
- 正式数据**不**写入 IndexedDB；浏览器仅在必要时用 sessionStorage 或带 TTL 的 localStorage 暂存
- 通过本机 Node 小服务读写磁盘；服务只监听本机

## 6. 页面结构

- `/` 练习
- `/library` 词库
- `/stats` 统计
- `/settings` 设置

## 7. 非目标（本版不做）

云同步、排行榜、对战、课程体系、AI 生成文、Electron 壳、中文输入法整词确认模式。

## 8. 验收要点

1. 可增删改练习文本，刷新后仍在（本机文件）
2. 打字过程错误可见，可退格
3. 结算指标与规则一致
4. 限时模式到期自动结束
5. 可查看并清空成绩
6. 可迁移数据目录且旧目录不再保留业务文件副本
7. 配置目录不可在界面中修改路径
8. 需先启动应用（含本机文件服务）再使用
