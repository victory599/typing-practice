# 本地打字练习

在浏览器里练习打字，词库和成绩保存在你自己的电脑上，不用注册账号。

## 能干什么

- **打字练习**：选一篇文本开始练；打错会标红，可以退格改
- **多种模式**：自由练完，或限时 1 / 3 / 5 分钟
- **即时反馈**：练习时看到速度（WPM）、准确率、用时和进度
- **词库管理**：自己新增、修改、删除练习文本；自带几篇范文
- **成绩统计**：查看历史成绩，也可以一键清空
- **数据在本机**：词库和成绩是本地文件；配置固定在应用目录，数据目录可以迁到你指定的文件夹

## 怎么启动

1. 打开终端，进入本项目目录 `typing-practice`
2. 首次使用先安装依赖：`npm install`
3. 启动：`npm run dev`
4. 终端会同时提示两个地址，请打开**【浏览器访问】**地址：
   - 浏览器访问：`http://127.0.0.1:5173`（页面）
   - 本机文件服务：`http://127.0.0.1:8787`（给页面读写本地数据用，一般不用手动打开）
5. 用完后：可以先关网页；若不再使用，在终端按 **Ctrl+C** 结束程序

若提示端口被占用：先结束旧进程再启动（例如 `lsof -i :8787` 查看后 `kill -9 <PID>`）。

说明：需要先启动本应用，页面才能读写本机上的词库和成绩。只打开浏览器、不启动程序是无法使用的。

## 数据存储

- 配置在应用里的 `config` 文件夹（路径固定，设置页不能改）
- 词库和成绩默认在应用里的 `data` 文件夹；可在「设置」里改到其他本机目录（会把文件移过去，不留两份）

 📌 清空浏览记录一般不会删掉这些文件；删文件夹或在应用里清空成绩才会去掉对应内容。

## 使用提示

- 练习页点一下打字区域再输入
- 词库页可以维护自己的练习文
- 统计页可查看或清空成绩
- 设置页可改默认模式，以及迁移数据目录
